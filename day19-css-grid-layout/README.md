# Day 19 - CSS Grid

## Topics Covered

- CSS Grid Layout
- `display: grid`
- `grid-template-columns`
- `repeat()`
- Fractional units (`fr`)
- `grid-auto-rows`
- `minmax()`
- `gap`
- `row-gap`
- `column-gap`
- `grid-column`
- `grid-row`
- `place-content`
- Nested Grid

## Practice

Practiced creating layouts using CSS Grid and controlling the size, spacing, and positioning of grid items.

Also practiced:

- Creating columns using `grid-template-columns`
- Using `repeat()` with `fr` units
- Creating flexible rows using `minmax()`
- Positioning grid items across columns and rows
- Using `grid-column` and `grid-row`
- Centering content using `place-content`
- Using Grid inside individual grid items
- Controlling spacing with `gap`, `row-gap`, and `column-gap`
