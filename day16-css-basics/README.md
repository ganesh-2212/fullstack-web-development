# Day 16 - CSS Position Property

## Topics Covered

- CSS `position` property
- `position: relative`
- `position: absolute`
- `position: fixed`
- `position: sticky`
- `top`, `left`, `right`, `bottom`
- `z-index`
- Positioning elements relative to their containers
- Fixed and sticky elements
- Smooth scrolling using `scroll-behavior`
- Sticky headers and footers
- Fixed social media/sidebar elements
- `box-sizing: border-box`

## Practice

Practiced positioning elements using different CSS positioning methods and controlling their placement with `top`, `left`, `right`, and `bottom`.

Also practiced:

- Positioning an absolute element inside a relative container
- Moving elements using relative positioning
- Creating fixed elements that remain visible while scrolling
- Creating sticky headers and footers
- Using `z-index` to control stacking order
- Creating a fixed social media section
- Using smooth scrolling with `scroll-behavior: smooth`
