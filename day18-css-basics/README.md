# Day 18 - CSS Flexbox

##Topics Covered

- Flex item sizing with `flex`
- `flex-grow`
- `flex-shrink`
- `flex-basis`
- `order`
- Using `flex` shorthand
- Applying different flex values to individual items
- Centering content inside flex items

## Practice

Practiced controlling individual flex items using the `flex` shorthand and changing their size and position within the flex container.

Also practiced:

- Using `flex: 1 1 150px`
- Understanding the relationship between `flex-grow`, `flex-shrink`, and `flex-basis`
- Giving different flex values to individual items
- Changing the visual order of flex items using `order`
- Using Flexbox inside a flex item to center its content
