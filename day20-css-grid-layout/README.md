# Day 20 - CSS Grid Layout

## Topics Covered

- CSS Grid layout structure
- `grid-template-areas`
- `grid-area`
- Creating page layouts with Header, Main, Sidebar, and Footer
- Defining grid columns using `grid-template-columns`
- Defining grid rows using `grid-auto-rows`
- Assigning elements to named grid areas
- Nested Grid layouts
- Combining parent and child Grid layouts
- Using `gap` and padding in Grid layouts

## Practice

Practiced creating a complete page layout using CSS Grid with separate Header, Main, Sidebar, and Footer sections.

Also practiced:

- Creating named grid areas using `grid-template-areas`
- Assigning elements using `grid-area`
- Creating a sidebar layout
- Using Grid inside the main content area
- Combining multiple Grid layouts
- Controlling spacing between sections using `gap`
