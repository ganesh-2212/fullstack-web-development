# CSS Media Queries

Practice project covering CSS media queries and responsive design.

## Topics Covered

* `@media` queries
* `min-width` and `max-width`
* `max-height`
* `min-aspect-ratio`
* Responsive background changes
* Conditional element visibility
* Combining multiple media-query conditions
* Sticky header and footer
* CSS Grid and Flexbox basics

## Media Query Examples

```css
@media screen and (min-width: 500px) {
    /* Styles for screens 500px and above */
}

@media screen and (min-width: 700px) {
    /* Styles for screens 700px and above */
}

@media screen and (max-height: 450px) and (min-aspect-ratio: 7/4) {
    /* Styles for short and wide screens */
}
```

## Purpose

To understand how CSS changes the layout and styling based on viewport size and screen characteristics.
