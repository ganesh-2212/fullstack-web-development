# Day 17 - CSS Flexbox

## Topics Covered

- CSS Flexbox
- `display: flex`
- `justify-content`
- `align-items`
- `flex-direction`
- `flex-wrap`
- `flex-flow`
- `gap`
- `align-content`
- `space-around`
- `space-between`
- `space-evenly`
- `row`, `row-reverse`, `column`, `column-reverse`
- `min-height` and `max-width`
- Centering and distributing flex items

## Practice

Practiced creating flexible layouts using CSS Flexbox and controlling the alignment, direction, wrapping, and spacing of flex items.

Also practiced:

- Aligning items using `justify-content` and `align-items`
- Changing the direction of flex items
- Wrapping items using `flex-wrap`
- Combining direction and wrapping using `flex-flow`
- Controlling spacing using `gap`
- Distributing multiple flex lines using `align-content`
- Using `space-around`, `space-between`, and `space-evenly`
- Creating responsive container layouts using `min-height` and `max-width`
