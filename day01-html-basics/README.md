# Day 01 – HTML Basics

## Task

Built a professional student profile webpage using only HTML.

## Concepts Practiced

* Headings (`h1`, `h2`)
* Paragraphs
* Lists (`ul`, `ol`)
* Definition list (`dl`, `dt`, `dd`)
* `abbr`
* `address`
* HTML entities (`&nbsp;`, `&copy;`)

## Files

* `index.html`

## Outcome

Learned the basic structure of an HTML webpage and created a clean portfolio-style profile page.
