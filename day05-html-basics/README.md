# Day 05 – HTML Practice Project

## Overview

Built a multi-page restaurant website, **Siya Momos**, by combining the HTML concepts learned so far.

## Pages

* `index.html` – Home page, About section, menu table, and navigation
* `contact.html` – Contact form and restaurant information
* `shophours.html` – Working hours and restaurant details

## Concepts Practiced

* HTML document structure
* Semantic HTML
* Headings, paragraphs, lists, and links
* Internal and cross-page navigation
* Images, `<figure>`, and `<figcaption>`
* Tables with `rowspan` and `colspan`
* `<thead>` and `<tbody>`
* `<details>` and `<summary>`
* Description lists
* Forms, inputs, labels, fieldsets, and buttons
* IDs and anchor links
* Favicon and external CSS linking
