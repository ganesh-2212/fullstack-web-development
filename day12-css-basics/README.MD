# Day 11 - CSS List Styling and Navigation Menu

## Topics Covered

* `list-style-type`
* `list-style-position`
* `:nth-child()` pseudo-class
* `:nth-child(odd)`
* `::marker` pseudo-element
* Custom list markers
* `:hover` pseudo-class
* Link styling
* Borders and border radius

## Practice Project

Created a simple navigation menu using HTML and CSS.

The project includes:

* Removing default list styles
* Styling navigation items
* Adding borders and rounded corners
* Styling links
* Creating hover effects for navigation items and links
* Applying spacing and alignment
