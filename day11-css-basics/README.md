# Day 11 - CSS List Styling

## Topics Covered

* `list-style-type`
* `list-style-position`
* Styling ordered and unordered lists
* `:nth-child()` pseudo-class
* `:nth-child(odd)`
* `::marker` pseudo-element
* Customizing list marker color, font, and size
* Using custom content for list markers

## Practice

Practiced styling ordered and unordered lists by changing list types, marker positions, and marker appearance. Also practiced selecting specific list items using `:nth-child()`.
