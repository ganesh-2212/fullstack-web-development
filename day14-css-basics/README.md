# Day 14 - CSS Float

## Topics Covered

* CSS `float` property
* `float: left`
* `float: right`
* `clear` property
* `clear: both`
* Managing floated elements
* `display: flow-root`

## Practice

Practiced positioning block elements using `float: left` and `float: right`.

Also learned how to:

* Add spacing around floated elements using margins
* Prevent elements from flowing around floated elements using `clear: both`
* Contain floated elements inside a parent using `display: flow-root`
